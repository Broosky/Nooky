# 💡 Nooky

A simple and compact USB-powered voltage regulator designed to replace 2×AA or 2×AAA batteries when powering 3V 
devices. Good for book nooks, LED decorations, small electronics, and other low-power battery-operated projects.

This board converts standard 5V USB power (or other DC input up to 7V) down to a stable 3V output using a spare LM317 
regulator module, allowing devices normally powered by batteries to run continuously without battery replacements.
